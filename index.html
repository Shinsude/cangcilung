Pengaturan AI

Alamat server AI (API standar OpenAI). Default: OpenRouter — akses banyak model gratis, tanpa kartu kredit. Bisa juga diisi server lokal sendiri (Ollama/llama.cpp, mis. http://192.168.1.5:8080).

Untuk OpenRouter: buat di openrouter.ai/keys. Tersimpan hanya di browser Anda (localStorage), tidak dikirim ke server lain. Untuk server lokal tanpa autentikasi, biarkan kosong.

Default (18+/dewasa): sao10k/l3-lunaris-8b — tanpa sensor, sangat murah (±Rp 700/juta token; butuh saldo kecil di OpenRouter). Alternatif 18+: gryphe/mythomax-l2-13b. Mau tetap gratis (tapi terfilter aman): nvidia/nemotron-3-nano-30b-a3b:free.
